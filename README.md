⚽ Football Hub

Overview

Football Hub is a simple Python CLI project about football clubs.

#####Features

* Browse 10 football clubs.
* Add, view, and remove favorite clubs.
* View club information, players, and competitions.
* View upcoming matches using Football API.
* Check user inputs with validation.
## User Stories
- As a user, I can browse football clubs.
- As a user, I can add and remove favorite clubs.
- As a user, I can view club information and matches.
Usage

Run the project:

python main.py

Choose from the menu:

* 1 - Browse Clubs
* 2 - Favorite Clubs
* 3 - Club Information
* 4 - Club Matches
* 0 - Exit
