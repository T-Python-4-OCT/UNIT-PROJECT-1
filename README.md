# Subscription Guardian

#### Overview : A CLI app that helps you keep track of all your monthly and yearly subscriptions (Netflix, Shahid, Spotify, Gym, etc.). It shows you how much you really spend, how many days are left before each subscription renews, and suggests which subscriptions you can cancel to save money. Most people forget their subscriptions and they keep renewing even when nobody uses them, this app solves that problem.

### Features & User Stories
#### As a user I should be able to do the following :
- Add a subscription (name, price, monthly/yearly, category, renewal date).
- View all my subscriptions in a table.
- See how many days are left until each subscription renews.
- Get reminders for the subscriptions that renew soon when I open the app.
- Get a spending report (monthly total, yearly total, and spending by category).
- See my spending by category as a chart in the terminal.
- Mark a subscription as used today.
- Get suggestions on what to cancel based on my usage (subscriptions I haven't used in a long time, or more than one subscription in the same category).
- Delete a subscription.
- Save my subscriptions so they are still there the next time I open the app.



#### Usage :
 Run the app by typing `python main.py`, then choose from the main menu:
 - type in 1 to add a new subscription.
 - type in 2 to show all your subscriptions and the days left until each one renews.
 - type in 3 to show the spending report.
 - type in 4 to mark a subscription as used today.
 - type in 5 to get suggestions on what to cancel.
 - type in 6 to delete a subscription.
 - type in 7 to exit.
