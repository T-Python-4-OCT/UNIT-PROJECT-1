# Taysir — تيسير

A Python-based Quran reader and audio application.

## Features
- Read Quranic verses.
- Navigate between verses and surahs.
- Search the Quran.
- View Tafsir Al-Muyassar.
- Listen to Quran recitation.
- Repeat verses and play surahs.

## Installation

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
