# SkyRoute ✈️ - Travel Agency CLI

A command-line travel agency written in Python. It shows 28 destinations (country, most famous
city, type, flight and hotel prices in SAR).

## Setup & Run

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Libraries: [rich](https://pypi.org/project/rich/) (colors and tables) and
[pyfiglet](https://pypi.org/project/pyfiglet/) (banner).
