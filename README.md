# تيسير — المصحف الصوتي والتدبّر

واجهة CLI عربية مكتوبة بـ Python، مخططة لتسهيل قراءة الآيات والتنقل بينها والبحث وعرض التفسير الميسّر من بيانات محلية موثوقة. يتضمن المشروع أيضاً نموذجاً أولياً اختيارياً لواجهة رسومية باستخدام Tkinter.

> **تنبيه بيانات:** لا يتضمن المستودع نصاً قرآنياً أو تفسيراً منسوخاً، لتجنّب تضمين نص ديني دون استيراد موثّق. لن يعرض البرنامج آيات أو تفسيراً حتى يضيف المستخدم ملفات بيانات من مصدر موثوق.

## المزايا الحالية

- واجهة طرفية عربية بتصميم أخضر داكن وزخارف نصية باستخدام `rich`.
- قراءة الآية الحالية والتنقل بين السجلات المتاحة.
- الانتقال إلى رقم سورة وآية.
- البحث في نص الآيات وأسماء السور الموجودة محلياً.
- عرض التفسير الميسّر إذا كانت بياناته موجودة.
- تكرار عرض الآية عدد مرات يحدده المستخدم (الصوت غير مفعّل في هذه المرحلة).
- واجهة رسومية أولية اختيارية عبر Tkinter.
- اختبارات وحدات باستخدام `unittest`.

## المتطلبات

- Python 3.10 أو أحدث.
- Terminal يدعم Unicode والعربية. يختلف دعم اتجاه النص والزخارف باختلاف الطرفية.
- لا يغيّر CLI خط الطرفية بنفسه. اختر الخط من إعدادات Terminal أو iTerm2. خط ثمانية يمكن استخدامه فقط إذا حصلت على ملفه وكان الترخيص يسمح بذلك؛ الواجهة الرسومية تعتمد على الخطوط المثبتة في النظام.

## الإعداد على macOS

```bash
cd Taysir
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## إعداد بيانات القرآن والتفسير

المصدر المقترح هو منصة مطوري برمجيات القرآن الكريم التابعة لمجمع الملك فهد لطباعة المصحف الشريف، حيث تتوفر بيانات المصحف والتفسير الميسّر:
https://qurancomplex.gov.sa/en/techquran/dev/

نزّل الحزمة الرسمية واقرأ دليل الاستخدام وشروط إعادة الاستخدام. لا تغيّر نص القرآن عند استيراده. بعد مراجعة بنية الملفات، حوّل البيانات إلى JSON وفق الشكل التالي. المثال أدناه **بيانات اختبار اصطناعية وليست آيات قرآنية**؛ لا تستخدمه كمحتوى ديني:

`data/quran.json`
```json
[
  {
    "surah_number": 1,
    "surah_name": "اسم تجريبي",
    "ayah_number": 1,
    "text": "نص تجريبي للاختبار فقط"
  }
]
```

`data/tafsir.json`
```json
[
  {
    "surah_number": 1,
    "ayah_number": 1,
    "text": "تفسير تجريبي للاختبار فقط"
  }
]
```

تأكد أن بيانات التفسير مأخوذة من ملف التفسير الميسّر الرسمي وأنك تلتزم بشروط المصدر، ولا تضع النص التجريبي في نسخة التسليم. سجّل اسم المصدر والإصدار وتاريخ التنزيل في توثيق البيانات. حافظ على النص القرآني كما ورد في المصدر.

مصدر النص القرآني الرقمي البديل: مشروع تنزيل (Tanzil). شروطه تتطلب الإسناد إلى المصدر، ووضع رابط إلى موقعه، وعدم تغيير النص:
https://tanzil.net/docs/Text_License

## التشغيل

```bash
python main.py
```

القائمة الرئيسية بالعربية. عند غياب البيانات، سيعرض البرنامج رسالة إعداد بدلاً من اختلاق آيات أو تفسير.

واجهة Tkinter الاختيارية:

```bash
python gui.py
```

## الاختبارات

```bash
python -m unittest discover -s tests -v
```

تستخدم الاختبارات بيانات اصطناعية مؤقتة فقط ولا تتضمن نصاً قرآنياً.

## قصص المستخدم

- بصفتي مستخدماً، أريد الانتقال إلى سورة وآية محددتين.
- بصفتي حافظاً، أريد تكرار الآية للمراجعة.
- بصفتي مستخدماً، أريد عرض التفسير الميسّر للآية الحالية.
- بصفتي مستخدماً، أريد البحث في النص المحلي.
- بصفتي مستخدماً كفيفاً، أريد واجهة لوحة مفاتيح واضحة، مع التخطيط لدعم الصوت لاحقاً.

## حدود النسخة الحالية

- لا يوجد تشغيل صوتي حتى الآن.
- لا يوجد تعرف صوتي أو ذكاء اصطناعي لفهم الأوامر في النسخة الحالية؛ الأوامر العربية المطابقة للقائمة مدعومة.
- لا يتضمن المشروع ملفات الخط أو الصور الزخرفية الخارجية. يستخدم CLI زخارف Unicode وألواناً؛ ويمكن تحسين الرسوم والخطوط في واجهة رسومية لاحقاً.
- لا تستخدم التطبيق بديلاً عن المصحف المعتمد للتحقق أو المراجعة الدينية.
